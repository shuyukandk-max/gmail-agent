## 一、1-9 號人格解析

## 六、全息圖計算公式（備查）

```
生日格式：日(DD) 月(MM) 年(YYYY) → 8 位數字 A B C D E F G H

A+B=I,  C+D=J,  E+F=K,  G+H=L
I+J=M,  K+L=N,  M+N=O（主性格）

N+O=Q,  M+O=P,  Q+P=R（事業發展）
I+M=X,  J+M=W,  X+W=S（工作人際）
K+N=V,  L+N=U,  V+U=T（家庭財富）

潛意識密碼 = reduce(O+I+L)
內心密碼   = reduce(O+M+N)
外心密碼   = reduce(S+R+T)
```

**驗證範例**（1974年7月8日）：
- A=0, B=8, C=0, D=7, E=1, F=9, G=7, H=4
- I=8, J=7, K=1, L=2
- M=6, N=3, O=**9**（主性格：9號 遠見型 木 智慧數/大愛數）
- P=6, Q=3, R=9
- X=5, W=4, S=9
- V=4, U=5, T=9
- 潛意識=1, 內心=9, 外心=9
